# Weather Dashboard using JavaScript

## Project Overview
A real-time weather dashboard built using JavaScript and REST API integration.

## Features
- Real-time weather fetching
- Search by city name
- Displays temperature, humidity, wind speed
- Async/Await implementation
- Error handling for invalid cities

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
- OpenWeatherMap API

## How to Run
1. Download project
2. Add your API key in script.js
3. Open index.html in browser
